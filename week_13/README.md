# 13주차 과제: LLM 페르소나 피드백 수집 및 A/B 테스트 기반 의사결정

## 🎯 1. 사용자 시나리오 기반 LLM 10인 페르소나 피드백 수집
`user_simulation.js`를 통해 서로 다른 구매 성향 및 탐색 패턴을 가진 10명의 LLM 가상 사용자를 구축하고 시나리오 테스트를 수행했습니다.

### 👥 수집된 사용자 페르소나 패턴 (총 10명)
- **분석가형/의심형 (user_01, user_05)**: 페이지 체류 시간이 길고 구매 전환율이 낮음.
- **충동형/트렌드세터 (user_02, user_04, user_08)**: 빠른 이탈 혹은 즉각적인 구매 전환 발생.
- **가성비/리뷰집착형 (user_03, user_06, user_07, user_09, user_10)**: 변수에 따른 유동적 흐름.

## 🎯 2. Feature Flag 기반 A/B 테스트 2주간의 운영 및 지표 측정
- **실험 주제**: `checkout_button_color` (Control: 기존 Red vs Treatment: 신규 Blue)
- **운영 기간 시뮬레이션**: 총 2주일
- **핵심 지표 (KPI)**: 구매 전환율 (Conversion Rate)

### 📊 수집된 2주간의 RAW 실험 데이터셋 (.csv)
![CSV Data](./csv_data.png)

### 📈 실험 데이터 분석 결과 Summary
- **Control (기존 Red 버튼 그룹)**: 평균 전환율 약 **38%** 기록
- **Treatment (신규 Blue 버튼 그룹)**: 평균 전환율 약 **56%** 기록
- **결과 해석**: 신규 블루 컬러 테마 및 UI 컴포넌트가 사용자의 시각적 피로도를 낮추고 클릭 유도율을 극대화하여 **지표가 약 18% 대폭 상승**함.

---

## 🎯 3. 최종 비즈니스 의사결정 기록 (Pivot vs Persevere)

> ### 📢 최종 결정: Persevere (기존 방향 유지 및 전체 배포)
> **이유 (Rationals)**:
> 1. 2주간 10개의 LLM 페르소나 시나리오 분석 결과, 신규 UI 테마(Blue)가 타겟 유저 군의 거부감 없이 구매 버튼 클릭을 유도함을 입증했습니다.
> 2. 핵심 지표인 구매 전환율이 통계적으로 유의미한 수준(18% 증가)으로 상승했습니다.
> 3. 따라서 서비스를 피벗(Pivot, 방향 전환)하지 않고, **현재 방향을 유지(Persevere)하여 전 수강생 및 사용자에게 100% 롤아웃(Rollout) 배포**하기로 최종 결정했습니다.
